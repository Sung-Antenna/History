# 주가지도 (Stock Price Map)

김종철 소장(유튜브 '김종철 원포인트레슨', 한국경제TV 와우넷 파트너)의 기법을
사용자가 제공한 강의 자막을 바탕으로 정리한 스킬이다. 강의 원문이 아니라 요약·구조화한 것이며,
출처와 근거는 `references/`에 있다.

> 이 스킬의 분석은 투자 판단 보조용이다. 수익을 보장하지 않으며, 최종 매매 결정과 책임은 사용자에게 있다.

## 1. 핵심 원리 — "큰 것이 가려면 작은 것이 파동을 줘야 한다"

주가는 한 번에 일직선으로 가지 못한다. 상위(큰) 이동평균선이 추세를 이어가려면,
바로 아래(작은) 이동평균선이 **올라갔다가 → 꺾였다가(조정) → 다시 가는** 파동을 반드시 만든다.
이 계층 구조가 "주가지도"다.

| 계층 | 큰 것 (추세) | 작은 것 (파동을 줘야 하는 선) |
|---|---|---|
| 대세 | **240선 ("대선")** 우상향 | **60선**이 오르다 꺾였다 다시 오름 |
| 중기 | **60선** 쭉 뻗음 | **20선**이 오르다 꺾였다 다시 오름 |
| (확장 해석) | 20선 | 5·10선 — 강의 일부에서 확인되지 않음, 아래 '미확인' 참고 |

따라서:
- 작은 선이 꺾이는 것 자체는 **추세의 끝이 아니라 정상적인 조정(파동)** 일 수 있다.
  많은 사람이 이 지점에서 "끝났다"고 판단하지만, 큰 선이 살아 있으면 원래 주가가 가는 방식이다.
- 반대로 상승하던 종목이 **60선을 깨고 내려가면** 추세가 꺾이는 신호로 본다
  (강의 예시: 엔비디아가 올라가다가도 결국 60선을 깨고 내려가야 하는 흐름).
- 올라가다 그냥 못 가고 꺾이는 것은 "파동이 아니다" — 즉 큰 추세를 만드는 정상 파동인지,
  추세 이탈인지 구분하는 것이 핵심이다 (강의 예시: 에코프로 상승 중 조정 구간).

## 2. 매수 자리 — 큰 선은 살아있고, 작은 선이 조정 후 다시 갈 때

강의에서 제시한 진입 논리:
1. 큰 선(예: 240)이 우상향 중이다.
2. 작은 선(예: 60)이 단기 조정을 받아 꺾였다.
3. 이 조정으로 **리스크가 어느 정도 축소된 상태**에서, 작은 선이 **다시 고개를 들 때 올라탄다.**

같은 원리를 한 단계 아래에도 적용한다: 60선이 뻗어가는 중이면 20선의 조정 후 재상승이 진입 후보다.

## 3. 분석 절차 (차트를 받았을 때)

사용자가 종목/차트를 주면 다음 순서로 답한다. 데이터가 없으면 추측하지 말고
현재가와 20·60·240 이동평균 값(또는 차트 캡처)을 요청한다.

1. **대세 판정 — 240선 방향**: 우상향 / 횡보 / 우하향. 우하향이면 매수 관점은 보수적으로.
2. **중기 판정 — 60선**: 240 위에서 파동을 그리며 올라가는가? 주가가 60선을 이탈했는가?
3. **단기 판정 — 20선**: 현재 20선이 상승 / 꺾임(조정) / 재상승 중 무엇인가?
4. **현재 위치 분류**
   - `눌림목 후보`: 큰 선 우상향 + 작은 선 조정 중 → 재상승 확인 대기
   - `진입 후보`: 큰 선 우상향 + 작은 선 조정 후 재상승 시작
   - `추세 진행`: 모든 선 정배열로 상승 중 → 신규 진입은 다음 조정을 기다림
   - `위험`: 주가가 60선을 깨고 하락 / 큰 선이 꺾임 → 신규 매수 보류, 보유 시 비중 축소 검토
   - `판단 보류`: 큰 선 자체가 하락 또는 데이터 부족
5. **하락장 생존 체크**: 큰 선이 꺾인 장에서는 작은 선 반등만 보고 들어가지 않는다.
   "큰 것이 살아 있는가"를 먼저 확인한다.
6. **결론**: 분류 + 근거(어느 선이 어떤 상태인지) + 다음에 확인할 신호(예: "20선 재상승 확인 시")
   + 무효화 조건(예: "60선 이탈 시 시나리오 폐기").

## 4. 답변 형식

```
[종목] 주가지도 판독
- 240선(대세): …
- 60선(중기): …
- 20선(단기): …
- 현재 위치: 눌림목 후보 / 진입 후보 / 추세 진행 / 위험 / 판단 보류
- 근거: …
- 다음 확인 신호: …
- 무효화 조건: …
※ 투자 판단 보조용 분석입니다.
```

## 5. 미확인 / 보강 필요

아래는 아직 사용자가 자료를 주지 않아 **확인되지 않은** 내용이다. 이 항목으로 판단할 때는
"강의 자료로 확인되지 않음"이라고 명시하고, 임의로 규칙을 만들어내지 않는다.

- 하락장 서바이벌의 구체적 대응 규칙 (강의 자막이 중간에서 끊김: 월봉 단위 조정 언급 이후)
- 손절 기준의 정확한 수치/조건
- 강의에서 언급된 용어 중 자막 인식이 불명확한 부분 ("…라고 하는 겁니다" 직전 용어)
- 관련 기법: 5파동, 바디크로스, 매미캔들, 10캔들 법칙, 종목군단, 주도주 찾기
  (영상 제목/기사로 존재만 확인, 내용 미확인)

새 강의 자료를 받으면 `references/`에 노트를 추가하고 이 파일의 원리·절차를 갱신한다.
